# umutcakir.com

Go-Live Checks for AI-built apps. Astro, no client JavaScript, one self-hosted font.

```sh
npm install
npm run dev      # local
npm run build    # outputs to dist/
```

Pages: `src/pages/index.astro` (home), `src/pages/go-live-check.astro` (service page).
Shared look: `src/layouts/Base.astro` + `src/styles/site.css`.
Old Turkish URLs redirect to `/` (see `astro.config.mjs`).
